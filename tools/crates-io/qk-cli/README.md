# qk-cli

qk (quick) is a standalone task runner written in Rust. It reads
Nx-compatible workspace configuration and is being developed to provide
dependency-ordered execution, precise affected selection and task caching.

This `0.0.0` release reserves the crate name for that active project. It is
a metadata-only prerelease and does **not** include the `qk` executable or
a usable library API. The functioning CLI will be published in a later
release; do not use this prerelease as a dependency.
